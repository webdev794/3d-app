Export from CorelDRAW first

This file is a CorelDRAW file (.cdr), which can't be opened here. Save a copy from CorelDRAW as SVG or PNG, then import that.

  1. In CorelDRAW, open the design and choose File › Export (Ctrl+E).
  2. Set Save as type to SVG to keep shapes and text editable here, or PNG for a picture (tick Transparent background for logos).
  3. Click Choose SVG or PNG below and pick the exported file.

Text looks different after import? In CorelDRAW, convert the text to curves (Ctrl+Q) before exporting.

Tools and shortcuts

Tools

Pick V · Shape (nodes) F10 · Freehand F5 · Rectangle F6 · Ellipse F7 · Text F8 · Polygon Y · Star S · Graph paper D · Spiral A · Eraser X · Zoom Z · Pan H · Interactive fill G · Mesh fill M · Eyedropper I (click a colour, then click objects to fill them)

Click a toolbox button again (or right-click it) to open its flyout: Smooth, Roughen, Attract, Repel, Knife, Bézier, Pen, B-Spline, Polyline, 3-Point Curve, Complex Star, basic shapes, dimensions, Blend, Contour, Drop Shadow, Transparency and more.

Curves and nodes

Convert to curves Ctrl+Q · Outline to object Ctrl+Shift+Q · Combine Ctrl+L · Break apart Ctrl+K

Shape tool: drag nodes, handles or segments · double-click a curve to add a node, a node to delete it · drag a box to select nodes · Shift+click adds · arrows nudge · Alt+drag a handle breaks symmetry.

Bézier / Pen: click for corner nodes, click-drag for smooth nodes, click the first node to close.
