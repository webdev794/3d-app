Put purchased garment models here (GLB format). They load automatically;
anything missing falls back to the built-in placeholder garment.

  rugby_jersey.glb        rugby_shorts.glb
  soccer_jersey.glb       soccer_shorts.glb
  basketball_singlet.glb  basketball_shorts.glb
  afl_guernsey.glb        afl_shorts.glb
  training_tee.glb

Name the parts inside each model so the showroom can colour them:
"Body", "Sleeve_L", "Sleeve_R" (main colour + pattern) and
"Collar", "Cuff", "Trim", "Waistband" (accent colour).
See docs/SHOWROOM.md for the full checklist.
